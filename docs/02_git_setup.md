# Setup Git on Linux

Use:

```bash
sudo apt install git -y
```

![Git Install](images/02-vm-updates/01-install-git.png)


Check git version using:

```bash
git version 
```

![Check Git](images/02-vm-updates/02-check-git.png)


Git clone your repository for this machine using:

```bash
git clone <your repository url>
```

![Git Clone](images/02-vm-updates/03-git-clone.png)


Check status of repository by running:

```bash
cd <your repository folder>

git status 
```

![Git Clone](images/02-vm-updates/04-git-status.png)
